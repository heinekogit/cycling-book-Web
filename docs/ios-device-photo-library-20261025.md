# 実走写真を端末の写真ライブラリにも保存する（2026-10-25）

実走中の写真は、従来どおりアプリ専用領域に元画像とサムネイルを保存し、走行終了後に開発用Supabase Storageの`route-photos`と`run_photos`へ同期する。アプリ専用領域は写真アプリではなく、アプリを削除すると未同期の写真が失われ得る。

追加仕様: iOSアプリの「設定」に「端末の写真ライブラリにも保存する」を設け、初期値はオフ、端末に設定値を保持する。オンにする際は写真ライブラリへの**追加のみ**の権限を求める。オンの状態で実走写真を撮影すると、まず従来のアプリ内保存を済ませ、走行終了・Supabase同期を待たずに写真ライブラリへ元画像をコピーする。ライブラリへのコピーに失敗してもアプリ内の写真を保持し、失敗を画面で知らせる。既に撮影した写真への遡及適用はしない。Supabaseの構成は変更しない。

iOS開発リポジトリに`expo-media-library`と設定画面・撮影処理を追加。TypeScript、ESLint、既存33テスト、Expo設定のiOS追加権限文言を確認済み。**ネイティブiOSプロジェクトへの反映と実機での許可・保存確認は未実施**。確認時は設定オフ/オン、権限拒否、通信なしで撮影、走行を終了せずアプリを再起動した場合の写真アプリ内の残存を試す。既存の開発ビルドには新しいネイティブモジュールが含まれないため、実機確認には新しいiOS開発ビルドが必要。
