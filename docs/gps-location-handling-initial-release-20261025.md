## 現行のデータの流れ

| 場面 | 取得・処理 | 保存・閲覧 |
| --- | --- | --- |
| iOSで実走を開始 | 走行開始時に「使用中」と「常に」の位置情報許可を確認。許可されなければ記録を開始しない。開始後は高精度の位置更新を使い、画面を閉じている間も記録する設定。精度50m超の点と直前から2m未満の移動は軌跡に採用しない。 | 記録中の座標・時刻・精度は端末のアプリ専用領域に走行下書きとして保存。停止・一時停止で位置更新を止める。未保存の走行は端末に残り、破棄操作で消す。実機での長時間・スリープ・強制終了時の動作は1-3/1-4で別途検証。 |
| 実走を終了・保存 | 採用した軌跡から距離、GeoJSONとポリラインを作る。通信できない場合は同期待ちとして端末内に置き、次の起動／復帰時などに再試行する。 | Supabaseの`runs`に精密な軌跡と走行日時をアカウントに紐付けて保存。走行写真は撮影時の位置を持ち、元画像・サムネイルをStorageへ同期する。同期済みの端末内写真ファイルは削除する。実走ログと写真は本人のアカウントで閲覧し、匿名には公開しない。 |
| Webでホーム地点を設定 | 本人が地図・座標入力で設定するか、「現在地を使う」を押した時だけブラウザの位置情報を取得する。 | `users.home_lat/home_lng`に保存。ルート編集の地図初期表示と公開時の500m除外判定に使う。ホーム座標・確認用の赤い円は公開画面へ出さない。自宅そのものを入力する必要はない。 |
| ルートを作成・公開 | 地図上の作図、GPX取込、実走からの変換などで位置を含むルートを作れる。公開は利用者の操作。現行UIではホーム地点が必要で、500m除外は初期値オンだがオフにできる。 | 非公開ルートは本人側のみ。公開時は公開用軌跡を`routes`へ保存し、元の形状を`route_private_geometries`へ保持する。除外オンならホーム地点から500m以内の軌跡・マーカー・写真を公開対象から外す。オフならホーム付近も公開される。公開ルートは匿名閲覧可能で、共有先以外にも閲覧され得る。 |
| 地図・検索・標高 | Web地図はOpenStreetMapタイルを読み込む。地名・住所検索は入力文字列をMapboxへ送る。Web/iOSの標高計算は経路のサンプル座標をOpen-Meteoの標高APIへ送る。iOS地図は端末のネイティブ地図を表示する。 | 外部サービスへ地図表示範囲、検索語、サンプル座標などのリクエストが出る。各サービス側のログ・保存期間は本リポジトリから確認できないため、公開文書で「位置情報を外部へ送らない」とは記載しない。 |

根拠: iOSの`src/lib/location-permissions.ts`、`src/hooks/use-ride-recorder.ts`、`src/background-location.ts`、`src/lib/ride-storage.ts`、`src/lib/ride-sync{,-model}.ts`、`app.json`。Webの`src/pages/{ProfilePage,RouteDetailPage}.tsx`、`src/features/routes/{api,geometry}.ts`、`src/features/maps/geocoding.ts`、`src/features/elevation/elevation.ts`、`supabase/migrations/20261017000000_baseline.sql`と`20261018000100_remove_legacy_routes_runs_policies.sql`。2026-10-18の2ユーザー・匿名RLS試験とWeb公開プレビュー／写真除外試験は`web-functional-smoke-test-20261018.md`に記録済み。

## 利用者向け説明の草案

> Cycling Bookは、利用者がiOSアプリで走行記録を開始したときに位置情報を取得します。画面を閉じて走行を続ける場合も、許可を受けて軌跡を記録します。走行中のデータはまず端末内に保存され、走行を保存するとアカウントに紐付けてサーバーへ同期します。同期前の走行は端末内に残ります。実走ログは自動では公開されません。
>
> 利用者がルートを公開すると、そのルートの位置・形状などを他の人が閲覧できるようになります。公開前に表示される地図を確認してください。設定したホーム地点から500m以内を除外すると、その範囲の軌跡・マーカー・写真は公開対象から外れます。除外をオフにした場合はホーム付近も公開されます。500m除外だけで自宅や日常の行動場所を特定できなくなる保証はありません。
>
> 地図表示、地名検索、標高計算のために、地図の表示範囲、検索語、経路の一部の座標が外部サービスへ送信される場合があります。利用するサービスとデータの扱いはプライバシーポリシーで案内します。

この文面は確認済みの「500m除外をオフにできる」方針を反映した草案。写真自体の取扱い・メタデータと端末ライブラリへの保存は6-4、アカウント／データ削除は6-6で扱う。

## 公開前の確認・決定

1. **公開時の500m除外:** 初期値オン・任意オフを維持する方針は確認済み。現行のDB関数はクライアントから渡された公開用軌跡・除外IDを保存し、サーバーがホーム距離を再計算して強制する仕組みではない。このため「500m以内は必ず非公開」とは説明しない。公開プレビューと、オフ時にホーム付近が公開される警告を維持する。
2. **画面内の説明:** Webプロフィールのホーム地点説明に、ルート作成時の地図初期表示と公開時の500m除外中心という二つの用途を追記した。Webのビルドと変更ファイルのlintは通過。iOSの位置情報許可文言は走行中・バックグラウンド記録の用途を説明している。開発版への配布と画面確認は別途行う。
3. **保存期間と削除:** 実走・下書き・同期待ち・公開／非公開ルート・ホーム座標の保存期間、および利用者が削除した際のDB・Storage・端末データの消去範囲を6-6と合わせて確定する。現行コードから一律の自動削除期間は確認できない。
4. **外部サービスの表示:** Mapbox、OpenStreetMapタイル、Open-Meteo、iOSのネイティブ地図、Supabaseの役割と送信される情報を、6-1/6-2の公開文書とApp Storeのプライバシー申告に反映する。実際の契約条件・保存期間・公開ビルドでの通信は別途照合する。
5. **公開直前の再試験:** 本番で匿名から実走ログ・ホーム地点・除外された軌跡／写真を読めないこと、公開／非公開の切替と実走からのルート変換を再確認する。GPSのスリープ・バックグラウンド動作は1-3/1-4に残る。
