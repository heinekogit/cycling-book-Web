# 運用中のマイグレーション

`20261017000000_baseline.sql` は新規・空のSupabaseプロジェクト用。既存DBと `cycling-book-dev` では実スキーマを照合してCLI履歴に適用済みと記録しており、SQLを再実行してはいけない。

以後の14桁日時ファイルだけが前進変更である。変更は開発用DBで適用・検証し、同じファイルを本番扱いDBへ反映する。`db push --dry-run` の対象が予想どおりか確認してから実行する。履歴や適用順の詳細は `../../docs/db-migration-workflow-20261017.md` を参照。
