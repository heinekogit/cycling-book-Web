# ベースラインの出典

`001`〜`003` は既存DBの2026-10-15スキーマ・静的設定から抽出した。`004` は新規Supabaseプロジェクトの広すぎる初期GRANTを取り消す補正で、2026-10-17に開発用DBへ一度適用した。

空のプロジェクトへ再現する際は、これらを順番どおり適用する。CLIで再現する場合の正本は、4ファイルを同じ順番で組み込んだ `../migrations/20261017000000_baseline.sql`。既存DBと `cycling-book-dev` には既に構造があるため、**ベースラインSQLを再実行しない**。両DBのCLI履歴には実DBを照合したうえで適用済みとして登録した。

旧16本は `../archive/pre_baseline_20261017/` に保管し、ベースライン後に再生しない。新規環境ではベースラインと、その後の `../migrations/` の変更だけを使う。
